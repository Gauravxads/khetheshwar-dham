# 3 in One Scanner Landing Page

A one-page site people reach by scanning a QR code. It shows 3 buttons for **Shree Khetheshwar Dham**:

1. **Join the Samaj**: opens the registration form (https://samaj-join.vercel.app/)
2. **Instagram**: @shreekhetheshwardham
3. **Facebook**: the Shree Khetheshwar Dham page

## Where to change things

Everything is in `index.html`:

| What | Line |
|---|---|
| Browser tab title | 6 |
| Heading on the page | 45 |
| Text under the heading | 46 |
| Join the Samaj link | 48 |
| Instagram link | 54 |
| Facebook link | 60 |
| Footer text | 66 |
| Colours | 8 to 39 (the style section) |
